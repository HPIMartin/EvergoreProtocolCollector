# Process Learnings

A running log of where the process slipped and how we prevent it next time. The **Reviewer** agent
(see [knowledge-base/multi-agent-playbook.md](knowledge-base/multi-agent-playbook.md)) proposes a
ready-to-paste row whenever a rule was missed, even on a PASS; the planner session appends it (the
reviewer itself never writes). The point is that future work and future agents drift
*toward* the process, not away from it. Recurring items are promoted into the tool entry file (e.g.
`CLAUDE.md`) or the [engineering handbook](knowledge-base/engineering-handbook.md).

The table starts empty in a fresh adoption; rows accumulate as the project runs. Keep each row
terse: what happened, which rule it violated (cite the handbook section), and the concrete
prevention.
